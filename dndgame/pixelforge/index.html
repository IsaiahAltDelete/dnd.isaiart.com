pixelforge

Pixel-art sprites as plain text, so an AI agent can author them.

Python 3.8+ · no dependencies · 18 files · 106 KB

A language model can't push pixels around a canvas, but it can write and edit a character grid exactly. pixelforge keeps every sprite as .pxa text — a palette plus an ASCII grid — and renders PNG or animated GIF on demand. The image is a build artifact; the text is the source.

The part that makes it usable by an agent is preview: it renders the sprite large, with numbered rulers and a palette legend. The agent reads that image back, sees what's wrong, and the flaw maps to an exact (x, y) it can edit. Without coordinates, blind pixel work just drifts.

All made with the tool. Sources are in the download.

Install

Unzip and run. There is nothing to install — the PNG and GIF encoders are written against the standard library.

python pxforge.py --help
python selftest.py            # 47 checks, should print ALL PASS

Use

The loop an agent should follow:

  1. new a canvas, optionally over a proportion guide
  2. Write or edit the grid
  3. preview it, then read the rendered PNG back and find the flaw's coordinates
  4. Fix that cell; repeat from 3
  5. render, sheet or gif for final output
python pxforge.py new hero.pxa --size 24x32 --template humanoid32
python pxforge.py edit hero.pxa --replace 's=.' --outline 'K,diag'
python pxforge.py preview hero.pxa      # read this PNG, fix, repeat
python pxforge.py gif hero.pxa --fps 8

What preview gives the agent

Numbered rulers and a palette legend, so a flaw in the image has coordinates.

Format

@name  knight
@use   chr16          # built-in palette: key -> color
@scale 12
@frame idle
....KKKK....
...K2222K...

. is transparent. Every row must be the same width — validate enforces it and ascii -n prints ruler-aligned rows with the character delta marked on any bad one.

Watching it draw

watch serves a page that repaints on every save and flashes the cells that just changed, which is useful when a person wants to see the sprite being built.

python pxforge.py watch examples/dragon.pxa --port 8765

Instructions for the agent

The download includes claude-skill/SKILL.md. Copy it to ~/.claude/skills/pixel-art/SKILL.md and Claude Code will discover the tool on its own whenever a request involves sprites or pixel art — no need to explain it each time. Update the paths inside the file to wherever you unzipped it.

The skill's own text is the agent-facing brief: the loop, the format, the ops list, and the craft notes that keep output from looking like noise.
