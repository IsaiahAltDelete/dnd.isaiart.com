# score — curating and integrating the whole score

Owner: the `score` agent (Music fleet). Branch `overhaul/score`. Owns
`core/music.js` TRACKS (the first score's tracks), `trackForBiome`, the maps'
`music:` fields, and the new `core/music_catalogue.js`. Small hooks elsewhere
are listed under "Hooks outside my files".

## Plan (milestones, each committed)

- **M1 routing and tags.** Every track (57: 24 first-score, 14 sacred, 19
  secular) gets `contexts` and `weight`; first-score tracks get in-world titles.
  Every hand-built map's `music:` (def AND builder, which disagreed on 8 maps)
  names a context; procedural sites and mapgen themes too; `trackForBiome`
  returns contexts (marsh -> 'marsh', underdark -> 'underdark', crypt ->
  'crypt'). `musicForMap(map, { night })` in music.js is the one place a map
  becomes a context, so overworld's `mapTrack` shrinks to a call; wilderness
  and settlement contexts yield to 'night' after dark, and nightfall while
  walking re-requests the music. Battle music by danger: `battleCue(enc)` ->
  { context: battle | boss | dragon, intensity 1..3 }, tracks declare
  `intensity`, and `Audio.music(ctx, { intensity })` weights the pool toward it
  (tiny hook in audio.js); combatui asks the same cue (it was replacing the
  dragon theme with 'battle' on the first frame). Rest screen outdoors asks
  'camp', not 'town'.
- **M2 catalogue.** `Audio.catalogue()` -> [{ id, title, form, contexts, mood,
  weight, seconds, room, book }] from `core/music_catalogue.js` (liner notes:
  form, mood, source for every track). Land M1+M2.
- **M3 revisions.** Rewrite the weakest first-score tracks as real polyphony on
  the new instruments, keeping their ids: the most-heard first (town 59 maps,
  inn 43, shop 37, tense 22, dungeon 15, field, battle, boss, temple), then the
  rest as time allows. Old loops were 4-10 s (battle 6 s); new ones 30-70 s in
  period forms. Validated by `tools/score/check.mjs` (data + counterpoint).
- **M4 mix.** Render every track (`tools/music-render.mjs`), loudness table with
  `--reference -33.3`, peaks, clipping, layer balance (`tools/secular/balance.js`).
- **M5 audition page.** `output/music/index.html` (git-ignored): every track's
  WAV with title, form, contexts; `tools/score/index.mjs` writes it.
