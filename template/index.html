Inside the file

How it works

Edit
Turns on click-to-type. Tapping a placeholder selects it, so typing replaces it. The blue authoring tips only show in this mode.
Cover name
Fills every [Character Name] in the chapter until you type over one by hand. Footers and the contents list update themselves.
Level 20 sheet
Fill the point-buy table under “How the Numbers Were Built” (it checks for exactly 27) and the scores, modifiers, saves, skills, passive Perception, spell DC, initiative and average HP follow. Tap a circle for proficiency; tap a skill twice for Expertise.
Art slots
Tap “Add art”. Images are shrunk to WebP and stored inside the page.
Rows
+ Row and − Row sit under every table in Edit mode.
Labels
Official, Homebrew and Canon. Tap one in Edit mode to cycle it.
Combat Math
The calculator works whether or not you’re editing.
Autosave
Keeps your work in this browser as you go.
Save copy
Downloads a finished, standalone HTML file with everything baked in. That copy keeps its own separate autosave.
Reset
Wipes the chapter back to blank.
Print
Fits each page onto one letter sheet.

From the zip

Rebuild from source

src.html, style.css and app.js are inlined with every font and texture in assets/ as base64, so the output is one file.

# writes dist/handbook-chapter-template.html
python3 build.py

# screenshots every page at 1440px and 390px
python3 tools/shoot.py dist/handbook-chapter-template.html shots

# regenerate assets/ from a Homebrewery clone
python3 tools/prep_assets.py ../homebrewery

To start a new character chapter with Claude, hand it this folder instead of copying an old build.
