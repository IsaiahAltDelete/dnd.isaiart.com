## The API

```js
import { VFX } from '../render/vfx.js';
const h = VFX.play('nova', { from, to, dtype: 'fire', radius: 40, zoom: 2, onImpact });
await h.impact;   // the blow lands: damage numbers, hurt flash, knockback
await h.done;     // the last ember is out
VFX.cast(spell, { from, to, ... })        // = play(VFX.styleFor(spell), { spell, ... })
VFX.styleFor(spell, dtype)                // signature id, else the data style
VFX.flash(color, dur, strength)           // flat stepped tint on 'screen-fx'
VFX.freeze(sec)                           // hit-stop: every effect holds its frame
VFX.onHitstop = (sec) => ...              // crits call this (the battle's own hit-stop)
VFX.drawGround(ctx, camX, camY)           // the ground band, under the actors
VFX.glowStrength = 1                      // scales every light pool
```
opts: `from`, `to` (points in the caller's space, a body's height above the
feet), `color`, `dtype`, `radius` (caller px), `zoom` (screen px per art px:
the battle's 1 or 2), `layer` ('fx' default), `onImpact(x, y)`, `spell`,
`victims` (points: chains, auras, multi-dart), `dir`, `count` (darts, rays),
`blocking` (FX.busy() stays true until impact + `hold`), `ground` (px from `to`
down to the feet; default 8*zoom), `image` + `anchorX/anchorY/imageScale`
(death dissolve: the sprite canvas), `tag` (draw only this effect's cell).

VFX registers itself with FX (`FX.addSystem`): it ticks in `FX.update`, draws
inside `FX.draw` (so every scene that draws FX shows it), keeps `FX.busy()` true
while a blocking effect has not landed, clears with `FX.clear()`, and its
flashes go out through `FX.drawScreen` on 'screen-fx'. Light goes to the Stage
'glow' layer when drawing into a res-1 world layer, else blends into the ctx.

## Rendering rules (the look)

- Everything on whole art pixels (an art pixel is `zoom` screen px), fillRect
  spans only: midpoint circles/ellipses, Bresenham lines, no arcs, no AA.
- Colour over life walks a palette.js ramp read hottest first (`LIFE[kind]`,
  `FIRE_LIFE` white > yellow > orange > red > ember > smoke).
- Light pools: two hard-edged stepped discs, radius capped at 22 art px, in a
  SATURATED version of the effect's hue (`lightOf`). Pale additive light on
  grass only greys it; large soft pools read as blurry blobs. Keep them small.
- Smoke is a shaded puff (body tone + a lighter cap offset up-left), solid
  while thick, thinning by 50% / 25% dither at the end of its life. Only fog
  and darkness-type clouds (dens < 0.45) are see-through all along. Never
  dither a puff under 3px across (it makes glyphs).
- Flashes are a flat tint stepping down in three levels (a 4x4 dithered flash
  read as a screen door over the whole field).
- Scorch decals are two or three steps under the soil, never black, at least
  10px across (a mark under a creature is otherwise hidden by its feet), and
  fade by thinning.
- Ground band (z 0: decals, rings on the ground, circles, webs) goes UNDER the
  actors when the scene calls `VFX.drawGround` before its sprites.

## For the battlefield agent: wiring `combatui._castFX` and `_impact`

Do not change the call sites' data flow; swap the bodies. `from`/`to` are the
screen points `_castFX` already receives (`_fxAt(u)`, a body's height above the
feet); `zoom` is `this.zoom`.

```js
import { VFX } from '../render/vfx.js';

_castFX(style, from, to, color, o = {}) {
  const spell = o.spell || null;
  // A spell with a signature (Fire Bolt, Magic Missile...) uses it; the data
  // style otherwise; plain weapon shots stay 'arrow'.
  const id = spell ? VFX.styleFor(spell, o.dtype) : style;
  VFX.play(id, {
    from, to, color, dtype: o.dtype, spell, zoom: this.zoom,
    radius: o.radius, dir: o.dir, victims: o.victims, blocking: o.blocking,
    count: o.count,                       // eldritch blast beams, scorching rays, missiles
    onImpact: o.onHit ? () => o.onHit(to.x, to.y) : null,
  });
}
```
- `_castFX` callers that pass `style === 'nova' || 'burst' ? 'aura' : style`
  for heals (combatui ~2680) can pass the spell and let `styleFor` decide.
- `_impact(target, crit, spell, dealt, attacker, dtype)`: for weapon damage,
  replace the `FX.burst/ring/beam` spray with
  `VFX.play(crit ? 'crit' : 'hit-' + (dtype in {piercing,bludgeoning} ? dtype : 'slash'), { from: attackerPoint, to: p, dtype, zoom: this.zoom, dir })`;
  keep the flash/recoil/shake/hit-stop logic that is not particles. For spell
  damage the spell's own style already drew its impact; keep only the hurt
  flash and numbers. Set `VFX.onHitstop = (s) => this._hitstop(s)` once so a
  crit's hit-stop is the battle's own.
- Death: `VFX.play('death', { to: p, zoom: this.zoom, image: spriteCanvas, anchorX: w/2, anchorY: h, ground: 10 * this.zoom })`
  then stop drawing the unit (the dissolve IS the body for 1.1 s).
- Ground band: in `_drawField`, call `VFX.drawGround(ctx, -o.x, -o.y)` in the
  'deco' pass (after deco, before `_drawUnits`). Then scorches, shock rings and
  summoning circles sit under the feet.
- `FX.draw` already draws VFX; nothing else is needed for it to show.

## Tools

- `vfxlab.html`: every style live with replay buttons; `set` = every style /
  data styles x damage types / one spell per look; `strip=N` renders N frames
  per effect deterministically (`every=ms` or `auto`, which crowds frames
  early); `bg` grass, stone or dusk; `zoom` 1 or 2.
- `tools/vfxprobe.js` (a shot.mjs --script): puts the lab over the game and
  pages it. Every --frames shot turns a page (shot.mjs awaits
  `window.SHOT_NEXT` between frames — the one-line hook I added to shot.mjs;
  any probe can use it):
  `$NODE tools/shot.mjs --scenario none --scale 4 --script tools/vfxprobe.js --frames 10 --every 150 --out output/vfx/styles.png`
  `--eval "window.VFXPROBE={set:'types'}"` for the damage-type grid (13 pages).
